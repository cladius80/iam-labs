# IAM Labs

Hands-on Identity & Access Management labs using **Okta** and **Microsoft Entra ID**.

| # | Lab | Topics |
|---|---|---|
| 01 | [IAM Fundamentals](lab-01-iam-fundamentals/) | User creation, group assignment, password reset, account disable, audit log validation |
| 03 | [App Integration & SAML SSO](lab-03-app-integration-sso/) | Zoom app onboarding, SAML SSO configuration, user/group assignment, SCIM provisioning concepts |
